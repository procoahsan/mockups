Delegate (Mobile)

Own country roadmap only. Timeline read-only in Submitted/Approved. Edit controls in Draft/Rejected. Approve/Reject in Submitted. Request Amendment in Approved. Comments in Submitted/Rejected/Approved. Notification Preferences always.

CBD Staff (Mobile)

All countries via country switcher. Generate in Not Started. Edit/Submit in Draft/Rejected. Re-submit in Rejected. Create Revision in Approved. Comments in Submitted/Rejected/Approved. Cohort Analytics hidden.

Mission Manager (Mobile)

All countries via country switcher. Edit only assigned mission types (Gap Analysis, Laboratory) in Draft/Rejected. No Generate, Approve/Reject, Cohort Analytics, Admin Config. Comments in Submitted/Rejected/Approved.

Admin (Mobile)

All CBD Staff capabilities plus Cohort Analytics, Algorithm Config, Audit Trail, User Management. Generate for any country. Create Revision in Approved. Full system access.
