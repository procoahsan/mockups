PVS Roadmap Planner

Welcome to the HTML prototype for the World Organisation for Animal Health (WOAH). This hub connects all 7 designed screens of the Roadmap Planner module. Built with TailwindCSS and Alpine.js, ready for stakeholder presentation.

1. Timeline Layout

The core horizontal timeline spanning five annual columns with activity cards.

2. Activity Cards

Designs for standard cards, AI-generated cards, and inline timeline bar variants.

3. Colour Coding

Design System

Comprehensive colour scheme for mission types, source attribution, and WCAG compliance.

4. Status Badges

Design System

Complete set of status badges across the roadmap lifecycle, in three size variants.

5. Executive Summary

Dashboard

At-a-glance analytics, budget projections, mission breakdowns, and cohort insights.

6. Filters & Export

Comprehensive filter bar states, dropdown anatomy, and export menu interactions.

7. Edit Flow

Edit mode, floating toolbar, detail drawer, and AI vs manual visual distinction.

8. Generate Roadmap

AI Feature

LLM auto-generation of 5-year activity roadmap based on evaluation scores and mission history.

9. Approval Flow

Workflow

Whole-roadmap review process including CBD submission, Delegate review diff, and lock state.

10. Notifications

System

Dropdown alerts, inline timeline banners for overdue/milestones, and automated email templates.

11. Mobile Layout

Responsive

375px viewport adaptation showing vertical timeline accordion, tabbed summary, and bottom sheet filters.

Designed for World Organisation for Animal Health (WOAH)
